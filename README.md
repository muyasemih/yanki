# 🔊 Yankı (Echo)

> Find your way through total darkness using sound — but every sound you make draws the creatures closer.

**Platform:** Browser (desktop & mobile) · **Built with:** HTML5 Canvas, vanilla JavaScript, Web Audio API · developed with AI-assisted coding

> 🔒 This is a **showcase repository**. The source code is kept private.

---

## 🎮 About the Game

Yankı is a minimalist stealth-horror game. The screen is pitch black; the only way to see is to send out a sound wave and watch the walls briefly light up as the echo returns.

- 🌊 **Echolocation** — emit sound pulses to reveal the maze for a moment
- 👂 **Sound is a risk** — creatures hunt by hearing; walking is quiet, running is fast but loud
- 🪨 **Throw stones** to create distractions and lure creatures away
- 🎧 **Positional audio** — with headphones, the hum of the exit and the creatures' footsteps tell you their direction
- 📱 Touch controls for mobile

## 🛠️ Technical Highlights

- **Zero dependencies** — a single self-contained HTML file
- Sound-wave propagation and wall-reveal rendering on **Canvas 2D**
- **Spatial audio** with the Web Audio API (stereo panning and distance attenuation), all sounds synthesized in code
- Creature AI that reacts to noise events from the player and the environment
- Persistent progress via `localStorage`
